# Tachyon releases

Download installers for the Tachyon desktop app. The source code is private; this repository only hosts release files.

Get the installer for your system from [Releases → latest](https://github.com/sleipnir-labs/tachyon-releases/releases/latest):

| System | File |
|---|---|
| macOS | `Tachyon-Setup.dmg` |
| Linux (x86_64) | `tachyon-setup.AppImage` |
| Windows (preview) | `Tachyon-Setup.exe` |

Each file is a small setup program. Open it and it downloads the newest Tachyon build for your machine, installs it and launches it.
